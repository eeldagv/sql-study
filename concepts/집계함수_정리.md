# 집계 관련 도구 총정리

## 개념설명

### WHERE
`WHERE`는 쿼리에 조건을 걸어주는 가장 기본적인 조건식이다.  
`WHERE`에는 관계연산자(`>`, `<`, `=`)와 논리연산자(`AND`, `OR`)를 사용할 수 있다.  
논리연산자 `AND`와 `OR`는 각각 `BETWEEN`, `IN`으로 대체할 수 있지만, `BETWEEN`은 조건이 숫자 범위일 때만 사용할 수 있다.  
또한 `WHERE`에는 집계함수를 쓸 수 없으니 주의해야 한다.  
  
  
### 서브쿼리
쿼리 안에 들어있는 또 다른 쿼리를 서브쿼리라고 하며, 괄호() 안에 써준다. 괄호 밖에 쓴 쿼리를 메인쿼리라고 한다.
  
예를 들어, '친구들 중에서 철수보다 용돈을 더 많이 받는 사람'을 구한다고 해보자. 이를 단계별로 나타내면,
  
1단계 : 우선 철수가 용돈을 얼마나 받는지 구해야 한다.  
2단계 : 철수가 받는 그 돈보다 더 받는 사람을 구해야 한다.

```sql
SELECT 이름
FROM 친구
WHERE 용돈 > (철수가 받는 용돈);
```
  
이 때 1단계에서 수행하는 것 = 철수가 받는 용돈을 구하는 것 = 서브쿼리  
2단계에서 수행하는 것 = 그 돈보다 더 받는 친구를 구하는 것 = 메인쿼리이다.
  
'철수가 받는 용돈'을 구하는 쿼리를 따로 써보면
  
```sql
SELECT 용돈
FROM 친구
WHERE 이름 = '철수';
```
  
이고, 이것을 메인쿼리 안에 작성하면
  
```sql 
SELECT 이름
FROM 친구
WHERE 용돈 > (
    SELECT 용돈
    FROM 친구 
    WHERE 이름 = '철수'
);
```

서브쿼리를 먼저 계산하고, 메인쿼리가 동작한다. 즉, 서브쿼리의 답을 먼저 구하고, 그 구한 답으로 메인쿼리의 답을 구하는 것이다.  

서브쿼리를 작성하는 위치에 따라 이름과 위치가 각각 다르다.  
* WHERE 안 : 서브쿼리 -> 조건 확인용 값 또는 목록 구하기  
* SELECT 안 : 스칼라 서브쿼리 -> 각 행마다 계산값 딱 하나 구하기  
* FROM 안 : 인라인 뷰 -> 쿼리 결과를 임시 테이블로 만들어서 사용  
  
  
### GROUP BY
유형별로 개수 등을 알고 싶을 때, 컬럼에 데이터를 그룹화할 때 사용한다. (ex. 반별 평균, 종류별 개수 등)  
`GROUP BY`를 사용하면 행이 줄어든다.  
예를 들어, 이름, 반, 점수 컬럼이 있는 테이블에서 '반 별 평균점수'를 구하면 '반'과 '점수'만 필요하기 때문에 다른 정보는 모두 날아간다. 또한 각각 독립적인 행으로 구분되어 있던 '점수'가 합쳐지면서 행이 줄어드는 것이다.   
  
### HAVING
그룹화 한 컬럼에 조건을 걸 때 사용한다. `WHERE`는 그룹화 전에 조건을 걸고, `HAVING`은 그룹화 한 후에 조건을 건다는 차이가 있다.  
`GROUP BY`에 `HAVING`은 필수가 아니지만, `HAVING`은 `GROUP BY`가 필수이다.  
  
  
### 윈도우 함수
`GROUP BY`를 사용하면 필요 없는 정보가 날아가면서 행도 줄어든다. 그런데 각 행을 모두 살려두면서, 그 행에 '반 별 평균 점수'를 새로운 컬럼으로 옆에 붙여두고 싶다고 해보자.  
이 때 사용하는 것이 윈도우 함수이다.   
  
```sql  
SELECT 이름, 반, 점수,
    AVG(점수) OVER (PARTITION BY 반) AS 반 평균
FROM 시험결과
```

`AVG(점수)` -> 평균을 구해줘  
`OVER` -> 근데 전체 말고, 나눠서 구해줘  
`PARTITION BY 반` -> '반'을 기준으로 나눠서  

`AVG`, `SUM`, `MAX`, `MIN`, `COUNT`와 같은 집계함수에 '`OVER`'가 붙으면 윈도우 함수가 된다.  
`OVER`란 '어떤 범위 안에서 계산해줘' 와 같은 뜻으로 보면 된다.(`OVER`는 '창문'이라고 생각하면 되는데, 큰 창문=큰 범위, 작은 창문=작은 범위 정도로 생각하면 된다.)  
  
즉, `GROUP BY`는 집계값만 필요할 때, 윈도우 함수는 원본 행을 유지하면서 집계값도 필요할 때 사용한다.  



## 어떨 때 무엇을 사용할까?
먼저 '결과를 어떻게 보여주고 싶은지'를 생각한다.  
  
|원하는 결과|도구|예시
|---|---|---|
|그룹별 집계값 (행 줄어듦)|GROUP BY|"물고기 종류별 평균 길이"|
|집계값에 조건걸기|GROUP BY+HAVING|"평균 길이가 33 이상인 종류만"|
|원본행 유지+집계값 옆에 붙이기|윈도우 함수(OVER)|"각 물고기+그 종류의 평균을 옆에 (행 유지)"|
|그룹별 '가장 ~한 행'의 세부정보|WHERE+서브쿼리|"종류별 가장 큰 물고기의 이름"|
  
이 예시들을 쿼리로 써보면 다음과 같다.  
  
1. **GROUP BY** : 물고기의 종류별 평균 길이 (행 줄어듦) 
```sql 
SELECT FISH_TYPE, AVG(LENGTH)
FROM FISH
GROUP BY FISH_TYPE;
```

2. **GROUP BY+HAVING** : 평균 길이가 33 이상인 종류만  
```sql
SELECT FISH_TYPE, AVG(LENGTH)
FROM FISH
GROUP BY FISH_TYPE
HAVING AVG(LENGTH) >= 33;
```

3. **윈도우 함수** : 각 물고기 + 그 종류 평균을 옆에 붙이기 (행 유지)  
```sql
SELECT ID, LENGTH,
    AVG(LENGTH) OVER (PARTITION BY FISH_TYPE)
FROM FISH;
```

4. **서브쿼리** : 종류별 가장 큰 물고기의 이름  
```sql
SELECT *
FROM FISH AS F
WHERE LENGTH = (
    SELECT MAX(LENGTH)
    FROM FISH
    WHERE FISH_TYPE = F.FISH_TYPE
);
```
